
# StudyDeck

Учебный командный проект по дисциплине
«Технология командной разработки программ».

## Описание проекта

Мобильное приложение для подготовки к экзаменам с использованием интервального повторения. Пользователь создаёт колоды вопросов и карточек, а приложение напоминает, что и когда нужно повторить. Предметная область — образовательные технологии и самообразование.

## Назначение проекта

Приложение предназначено для студентов и школьников, которым нужно готовиться к экзаменам или подобным работам. Оно помогает эффективнее запоминать материал за счёт научно обоснованного режима повторения и удобного мобильного формата. Пользователь получает инструмент, который сам планирует повторение и не даёт забыть пройденный материал.
